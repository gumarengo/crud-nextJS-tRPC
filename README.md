# CRUD Next.js + tRPC

Management system for ARTEFACT

## Technical Decisions (Less is More)
- **Framework:** Next.js 15
- **Backend:** tRPC and Zod. All typing is inferred from the back to frontend
- **Database:** in-memory
- **SSR:** Used at the home page
- **CSS:** Minimalist Tailwind

## How to run the project

1. Install dependencies: `npm install`
2. Start the server: `npm run dev`
3. Access: `http://localhost:3000`
